# 運営メンバー紹介画像の配置

`/info/operators` の各メンバーの**名前の直後・紹介文（主な担当）の直前**に画像を表示します。画像ファイルは `apps/frontend/public/images/operators/` に配置してください。Vueコードの変更・画像のimport・DB登録は不要です。

| メンバー | 画像ファイル名 |
| --- | --- |
| surumeneco(スルメねこ。) | `surumeneco.png` |
| カバ | `zawazawa123.png`（後日配置） |
| Loofgald | `Loofgald.png` |
| まど | `rnad0.png` |
| Kana(かな) | `shirokana.png` |

名前と拡張子は**大文字・小文字も含めて完全一致**させてください。画像は元の縦横比を維持し、画面幅内・最大高さ28remに収まるよう縮小します。小さい画像を無理に拡大しません。未配置または読み込みに失敗した画像は非表示にして、メンバーの名前と紹介文は残します。

開発中は画像を配置した後に `/info/operators` を再読み込みしてください。公開環境では画像ファイルもGitでコミットしてデプロイする必要があります。`public/` は静的配信対象です。画像のURLは `/images/operators/<ファイル名>` となります。カバさんの写真も、後日 `zawazawa123.png` を同じディレクトリに置けばページ側の追加修正は不要です。

画像の割り当ては今回受領したファイル名に基づきます。画像自体はこの変更でGitHubにアップロードしていません。現在の紹介文や担当表記は変更しません。
